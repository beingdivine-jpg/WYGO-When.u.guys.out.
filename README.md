# WYGO: When you guys out? - We Go 📅

> "Because 'Does next Sunday work for everyone?' is the most expensive question in the world."

---

##  The Heart of the Project
I built **WYGO** (When you guys out?) because I was tired of seeing great ideas for hangouts die in the group chat. We’ve all been there: 150 messages later, and nobody knows if the plan is actually happening.

WYGO is designed to take the friction out of friendship. It’s a coordination engine that treats your social life with the same architectural respect as a professional calendar. It’s about spending less time "planning" and more time actually hanging out.

---

##  The Coordination Flow
I engineered WYGO to be a straight line from "Idea" to "Event":

1.  **Drop the Spark:** Create an event with a location and a vibe.
2.  **The Invite:** Send a single link to the crew—no app install required for them to vote.
3.  **The Pulse:** Friends input availability or sync their personal calendars.
4.  **The Verdict:** The engine finds the "Best Fit" window where the majority is free.
5.  **Lock it In:** Confirm the event and let the notifications handle the reminders.

---

##  The Tech Stack
* **Frontend:** React + TypeScript + Vite (For a snappy, zero-lag interface)
* **Logic:** Custom Availability Polling Engine (Designed for multi-variable scheduling)
* **Styling:** Tailwind CSS + Framer Motion (Smooth transitions for a "lifestyle" feel)
* **Integration:** Calendar Sync APIs (Bridging the gap between work and play)
